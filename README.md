# Education_Planer

Домен: образование · Сложность: базовая

Описание: EduPlan держит в одном месте недельное расписание и задания с дедлайнами.

Решает хаос из скриншотов и групповых чатов: у каждой пары — аудитория,
преподаватель и время, у каждого задания — срок и статус. Целевая аудитория: студенты,
которые не хотят пропускать дедлайны.

Обязательные экраны (6–8):
1. Вход / регистрация
2. Недельное расписание (пары по дням)
3. Список курсов (поиск + фильтр по дню недели)
4. Карточка курса (преподаватель, аудитория, связанные задания)
5. Список заданий (фильтр по статусу и сроку)
6. Форма нового задания / редактирования (название, курс, дедлайн, приоритет)
7. Профиль пользователя
   
Обязательная функциональность по этапам:
L2: статические экраны расписания, списков и карточки с «зашитыми» данными
(Material 3).
L3: навигация расписание → карточка курса → задания (go_router); форма задания с
валидацией (обязательное название, дедлайн в будущем).
L4: состояние списков (отметка выполнения, сортировка по сроку) + Repository с
mock-данными.
L5: интеграция с backend-ом: GET/POST /courses, GET/POST /assignments, PUT /
assignments/{id} (смена статуса); JWT-аутентификация.
L6: полная локальная персистентность (расписание доступно offline), тесты, releaseсборка.

Модель данных backend:
- Course(id, name, teacher, room, weekday, startTime)
- Assignment(id, courseId, title, deadline, status, priority)
- Endpoint-ы: GET/POST /courses, GET/PUT/DELETE /courses/{id}; GET/POST / assignments, GET/PUT/DELETE /assignments/{id}. Аутентификация (POST /auth/ register, POST /auth/login) идёт из шаблона.

Бонус (по желанию): уведомление за N дней до дедлайна; месячный вид календаря;
процент выполненных заданий по каждому курсу.
